# image-processing-lab
A professional Flask + OpenCV web application for demonstrating all 10 Image Processing practicals.

Included practicals
Image representation, RGB/Grayscale, arithmetic and bitwise operations
2-D geometric transformations: Translation, Rotation, Scaling, Shearing, Reflection, Cropping
Spatial enhancement: Histogram Equalization, Smoothing, Sharpening, Thresholding
Spatial filters: Averaging, Gaussian, Median, Bilateral
Image inpainting: Telea and Navier–Stokes
Lossless compression: Huffman statistics + PNG lossless output
Morphology: Erosion, Dilation, Opening, Closing
Correlation-based object detection / template matching
RGB, HSV, YCrCb and Lab colour spaces
Canny, Sobel and Prewitt edge detection
